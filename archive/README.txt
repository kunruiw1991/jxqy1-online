剑侠情缘1（1997）DOS 硬盘整理版

从原始数据光盘提取游戏目录，附第二张音乐光盘 BIN/CUE。无需实体光盘，但背景音乐需要在 DOSBox 中挂载附带的 AudioCD.cue。原始游戏文件未修改。
在解压目录作为当前工作目录运行：dosbox -conf dosbox.conf
macOS M3 请使用支持 Apple Silicon 的 DOSBox 或 DOSBox-X；本包不含模拟器，也不是 macOS 原生程序。
如声音设置不匹配，可在模拟器内运行 C:\RPG\SETUP.EXE。
原始数据与音轨来自 https://archive.org/details/pc-the-legend-of-swordman-chs-cht_202211
下载时验证了两份源文件 SHA-1 与归档记录一致。未完成病毒扫描，未进行实际运行或通关测试。
